## 🚀 Features

- ✨ **Modern UI/UX** - Clean, minimalistic design with smooth animations
- 🎨 **Dark Mode Support** - Seamless theme switching
- 📱 **Fully Responsive** - Optimized for all devices
- ⚡ **Performance Optimized** - Fast loading times and smooth interactions
- 🎭 **Animated Components** - Built with Framer Motion for fluid animations
- 🔍 **SEO Optimized** - Proper meta tags and structured data
- 🌈 **Animated Gradient Background** - Subtle, minimalistic animated gradients

## 📦 Installation

### Prerequisites
- Node.js >= 16.14
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/vydyas/vydyas.github.io.git
cd vydyas.github.io

# Install dependencies
yarn install
# or
npm install
```

## 🚀 Development

### Start Development Server

```bash
yarn start
# or
npm start
```

This command starts a local development server and opens up a browser window at `http://localhost:3000`. Most changes are reflected live without having to restart the server.

### Build for Production

```bash
yarn build
# or
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

### Preview Production Build

```bash
yarn serve
# or
npm run serve
```

### Type Checking

```bash
yarn typecheck
# or
npm run typecheck
```

## 📤 Deployment

### GitHub Pages

Using SSH:
```bash
USE_SSH=true yarn deploy
```

Not using SSH:
```bash
GIT_USER=<Your GitHub username> yarn deploy
```

This command builds the website and pushes to the `gh-pages` branch.

### Other Platforms

The `build` folder contains static files that can be deployed to:
- **Vercel** - `vercel deploy`
- **Netlify** - Drag and drop the `build` folder
- **AWS S3** - Upload `build` folder contents
- **Any static hosting service**

## 🎨 Customization

### Update Personal Information

1. **Site Title & Tagline**: Edit `docusaurus.config.js`
2. **Profile Information**: Update `src/pages/index.tsx`
3. **Work Experience**: Modify `src/pages/experience.tsx`
4. **Projects**: Edit `src/pages/projects.tsx`
5. **About Section**: Update `src/pages/about.tsx`

### Styling

- Global styles: `src/css/custom.css`
- Component styles: `src/components/*/styles.module.css`
- Page styles: `src/pages/*.module.css`
